# Sumo Bot

A remote-controlled sumo robot built for a university competition. Designed from scratch — chassis modelled in Autodesk Fusion 360, assembled, wired, and programmed by a team of students.

## How It Works
The robot is controlled wirelessly via an Xbox controller connected to an ESP32 microcontroller. The ESP32 receives controller input and drives the motors accordingly.

## Components
| Component | Quantity | Details |
|---|---|---|
| Microcontroller | 1 | ESP32 |
| Controller | 1 | Xbox Controller (wireless) |
| Motor Controllers | 2 | TB6612FNG |
| Motors | 4 | TT Hobby Motors |
| Chassis | 1 | Custom — designed in Autodesk Fusion 360 |
| Power Supply | 1 | 7.4V LiPo Battery |
| Buck Converter | 1 | Steps down 7.4V to 5V for the ESP32 and Motor Controllers |
